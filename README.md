


# 📚 Library Management System

**Level:** Intermediate  
**Database:** `library_db`  
**Tools:** MySQL, MySQL Workbench

#### 📌 Project Overview

This project demonstrates the implementation of a Library Management System using SQL. It focuses on database design, table creation, data manipulation, and advanced querying to manage library operations, including books, members, employees, branches, and book issue and return records.

The project showcases how SQL can be used to organize library data and retrieve useful information for operational and management purposes.

#### 🎯 Objectives

1. **Database Setup:** Create and populate tables for branches, employees, members, books, issued status, and return status.
2. **CRUD Operations:** Perform Create, Read, Update, and Delete operations to manage library records.
3. **CTAS (Create Table As Select):** Create new tables based on the results of SQL queries.
4. **Advanced SQL Queries:** Write complex queries to retrieve information and analyze library operations.
5. **Book Issue and Return Analysis:** Work with issue dates, return dates, and member borrowing records.
6. **Data Retrieval:** Identify relevant information about books, members, employees, and library transactions.

#### 🧠 Key Skills Demonstrated

- Database and table creation
- Primary keys and foreign keys
- CRUD operations
- Filtering, sorting, and aggregate functions
- Joins and subqueries
- CTAS queries
- Date and interval operations
- Advanced SQL business queries

#### 🗂️ Database Tables

The project includes tables for:

- `branch` — Library branch information
- `employees` — Library employee details
- `members` — Library member records
- `books` — Book details and availability information
- `issued_status` — Book issue transactions
- `return_status` — Book return records

#### 💡 Project Outcomes

- Practice managing relational data across multiple tables.
- Understand relationships between books, members, employees, and branches.
- Retrieve information about issued and returned books.
- Strengthen SQL skills through practical library management scenarios.
